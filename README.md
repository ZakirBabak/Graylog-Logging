# Graylog Logging Infrastructure

## Centralisation et supervision des logs Linux et Windows

Projet réalisé dans le cadre de la formation TSSR.

---

## Description

Mise en place d'une solution complète de centralisation, collecte et analyse des logs avec Graylog, Rsyslog et Nxlog.

---

## Technologies utilisées

- Ubuntu Server 22.04
- Graylog
- Rsyslog
- Nxlog
- MongoDB
- Elasticsearch
- TCP/IP
- Hyper-V
